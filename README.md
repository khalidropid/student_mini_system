# Student Mini System

مشروع تدريبي مصغر لنظام الطلاب، صُمم ليكون مثالًا تطبيقيًا مباشرًا للمفاهيم الموجودة في المشروع الأصلي، ولكن في نطاق أكاديمي أبسط.

## الوظائف
- تسجيل المستخدم وتسجيل الدخول.
- إضافة الطلاب وعرضهم.
- إضافة المقررات.
- تسجيل الطالب في مقرر.
- إدخال درجة الطالب وتحديثها.
- حساب متوسط الطالب.
- عرض أعلى الطلاب.
- تخزين البيانات في JSON.
- Unit Tests.

## المفاهيم
Modules, Packages, dataclass, Enum, Type Hints, Docstrings,
*args, **kwargs, positional-only `/`, keyword-only `*`,
Higher-Order Functions, map, filter, sorted, Closures,
Decorators, functools.wraps, Custom Exceptions, Dependency Injection,
JSON Persistence, Authentication/Hashing, Unit Testing.

## التشغيل
```bash
python -m app
python -m unittest discover -s tests -v
```

لا توجد مكتبات خارجية مطلوبة؛ المشروع يعتمد على Python Standard Library.
